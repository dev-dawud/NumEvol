# NumEvol

Number Evolution (NumEvol) is a custom Math interpreter that simulates the evolution of numbers. 
Whenever a calculation breaks or cannot be solved within the limits of its current number set, the program dynamically evolves to the next mathematical dimension and says it to you.
(For example from Natural -> Complex numbers)

## Requirements
C++ 11 or later

## Installation

Use ``git clone`` to download the project.

```bash 
git clone https://github.com/dev-dawud/NumEvol.git
```
Before you run and test the project, make sure the compiler in Visual Studio or IDE of your choice, is set to **“Release (x64)”** to ensure smooth real time performance of the program.
